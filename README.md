# Decoshop

## Descripción
Decoshop es una aplicación web de una tienda de muebles. Permite visualizar productos, consultar sus detalles e ingresar a un formulario de inicio de sesión.

## Tecnologías utilizadas
- Node.js
- Express
- EJS
- HTML
- CSS
- JSON

## Funcionalidades
- Visualización de productos.
- Consulta de detalles de cada producto.
- Formulario de inicio de sesión.
- Formulario de sugerencias.

## Instalación y ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `npm install`.
4. Ejecutar `node app.js`.
5. Abrir `http://localhost:3000` en el navegador.
